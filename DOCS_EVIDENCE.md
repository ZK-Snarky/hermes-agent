## Gaps and ambiguities

- Official Hermes docs do not explicitly say platform adapters may never perform local subprocess routing. The documented adapter responsibilities are transport-centric, so “no sebOS policy in Photon” is an inference plus local convention.
- Official Hermes docs do not define Seb/Athena/sebOS boundaries. Those are local convention, supported indirectly by plugin/MCP/platform docs.
- Official Photon/Spectrum docs were inspected only through the published LLM index in this phase. Deeper provider pages and installed `spectrum-ts` source/types should be read before any Photon SDK-level code change.
- Profile plugin scoping is partly ambiguous in docs: profiles own skills/config/memory/sessions/gateway state, and clone-all copies plugins, but the exact per-profile plugin directory semantics need source verification before migration.
- MCP docs include a minor config rule tension: general config says non-secrets in `config.yaml`; MCP catalog install can put non-secret base URLs in `.env`. Treat this as a documented exception or maintainer decision.
- Apple Reminders/Calendar/Notes semantics are not Hermes-documented. In this phase, Apple behavior is cited from sebOS source only. If implementation changes touch EventKit/Shortcuts/AppleScript assumptions, read Apple docs first.
